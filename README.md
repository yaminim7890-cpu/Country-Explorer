# 🌍 Country Explorer

**Country Explorer** is a responsive React web application that allows users to explore countries around the world. It displays country flags, capitals, continents, currencies, and country codes using a GraphQL API.

## ✨ Features

- 🌎 Explore country information from around the world.
- 🔍 Search countries by name or capital.
- 🗺️ Filter countries by continent.
- 🏳️ Display country flags.
- 💰 View country currencies.
- 🌙 Dark Mode and Light Mode toggle.
- 💾 Save the selected theme using Local Storage.
- 📱 Responsive design for desktop, tablet, and mobile.
- 🔄 Refresh country data.
- ⚡ Loading and error handling.

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- GraphQL API
- Vite
- Local Storage

## 🌐 API Used

- Countries GraphQL API: https://countries.trevorblades.com/
- Flag Images: https://flagcdn.com/

## 📂 Installation and Usage

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/country-explorer.git
```

**2. Navigate to the project folder**

```bash
cd country-explorer
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL** displayed in your terminal.

## 📱 Responsive Design

The application is designed to work across:
- Desktop
- Tablet
- Mobile devices

## 🎨 Theme Support

Users can switch between Light Mode and Dark Mode. Their selected theme is saved in Local Storage and restored when they revisit or refresh the application.
